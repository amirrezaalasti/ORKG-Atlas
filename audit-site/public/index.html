Before you start

Each case shows a research question about papers in the Open Research Knowledge Graph, the answer a system returned (its SPARQL query and result rows), and a reference answer written by the study authors. Decide whether the system's rows answer the question. You will not see scores, which system produced the answer, or the other annotator's labels.

Work alone and do not discuss cases with the other annotator until both of you are done. Answers save automatically to the study server. You can stop and come back at any time, on any device: just enter the same annotator code.

How to judge
Correct
The rows contain the facts the question asks for, for the right papers. A different shape is fine: counts instead of one row per paper, extra title, year or URI columns, long instead of wide tables, a resource ID next to its label.
Partly correct
The right kind of answer with a real but limited defect: some papers missing or added because a filter is slightly too narrow or broad, or only one part of a multi-part question answered.
Wrong
The rows answer a different question: the wrong attribute, the wrong set of papers, values attached to the wrong papers, a generic label (such as “Data collection”) instead of the actual value, or nothing usable.
Can't judge
The case does not give you enough to decide. Say why in the note.
How to read a case
Start with the overview on each side: row and paper counts, and each answer column's most frequent values with the number of papers stating them (for an already aggregated answer, its own numbers). Compare the two overviews; open the rows or queries only when the overview does not settle it. Most cases take one to two minutes.
Reference
The reference shows one correct way to answer. It can be truncated (the row count says how many rows exist) and can itself be wrong; if you think so, tick the box under the verdict.
Keys
1–4 choose a verdict, N next case, P previous case (when not typing in a field).
